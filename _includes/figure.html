Used ~161 times. image - object with src, alt, shape, mobile_shape, position, mobile_position, width, height, fit class - extra class after "media" (hero-image, about-portrait, footer-portrait). Omit for none. eager - true for the first image on a page; adds fetchpriority="high". Every variable here is fig_-prefixed ON PURPOSE.
